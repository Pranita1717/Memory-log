# 🧠 Memory Log – Memory Assessment and Care System

Memory Log is a web-based memory assessment and care system designed to support cognitive exercises, memory assessments, and caregiving activities.

The application provides an interface for patients and caregivers, with additional administrative functionality.

## ✨ Features

- **User Authentication:** Register and log in to the application.
- **Patient Dashboard:** Access memory assessment and cognitive activities.
- **Memory Games:** Practice cognitive skills through interactive activities.
- **Cognitive Assessment:** Complete memory-related tests.
- **Progress Tracking:** Review assessment history and performance.
- **Caregiver Dashboard:** Support caregivers in accessing relevant patient information.
- **Admin Dashboard:** Provide administrative functionality.
- **Location Support:** Includes location-related functionality where supported by the browser and application configuration.
- **Responsive Interface:** HTML, CSS, and JavaScript-based user interface.

## 🛠️ Technologies Used

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Python, Flask
- **Database:** MongoDB
- **Database Driver:** PyMongo
- **Version Control:** Git and GitHub
